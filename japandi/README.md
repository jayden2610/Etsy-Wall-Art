# Japandi

Five single-line nature studies (J01 sakura, J02 koi, J04 pine, J05 bamboo, J06 crescent). J03 Fuji was dropped.

- Prompts: `line-art/prompts.md` (Set 1)
- Boards: `node line-art/generate-boards.mjs`
- Renders: `output/japandi/` (flat ratio folders — 4x5, 5x7, 11x14, ISO; no 2x3)
- Grok masters: `output/sources/grok-images/`
