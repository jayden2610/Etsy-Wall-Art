# Japandi + Botanical Wall Art — 12 Image Prompts

> **Theme:** Wabi-sabi single-line botanical + nature studies on warm beige paper. Continuous ink contour, off-center, vast negative space, no text, no frame, no fill. Locked palette, locked composition, locked style — only the subject changes between prompts.

---

## The Master Style Block (paste this in front of every subject)

```
A single continuous line drawing of [SUBJECT], drawn in one unbroken ink contour without lifting the pen. Wabi-sabi inspired: the line is organic and slightly imperfect, with subtle variations in stroke weight where the hand would naturally press harder. The subject is placed off-center in the lower-left or lower-right third of the composition. Vast warm negative space fills the upper and opposite side — at least 70% of the frame is intentionally empty. Warm beige paper background (#E8DDC9, soft cream, not white). Ink line in deep warm brown (#3A2E1F), not black. No shading, no cross-hatching, no fill, no gradient. No text, no watermark, no signature, no border, no frame, no background elements, no drop shadow. The image is a museum-quality botanical or nature study suitable for a Japandi interior — calm, minimal, timeless. Aspect ratio 2:3 vertical, print-ready at 300 DPI, edge-to-edge, no margins, no safe area. Photographed flat under soft natural daylight, no glare, no texture on the paper, no grain, no film stock. Style reference: wabi-sabi sumi-e ink drawing meets Scandinavian minimalist line art.
```

**How to use:** Copy any prompt below as-is. Each one already includes the master block — you do not need to combine anything. Paste straight into Grok Imagine (or GPT Image 2, FLUX.2 via fal, Nano Banana 2).

## Tips for consistent results across all 12

- **Run all 12 in one sitting** with the same model and same settings — this minimizes drift between prints.
- **Use the same aspect ratio every time** (2:3 vertical is locked into every prompt above).
- **If a print drifts** (too much detail, too dark, centered instead of off-center), re-run with only the offending sentence removed — for example if it adds shading, delete the "No shading" sentence entirely and re-run; the rest of the prompt still does the work.
- **Save the output filenames as `J01_sakura_v1.png`, `J02_koi_v1.png`, etc.** so you can iterate (`_v2`, `_v3`) without overwriting the keeper.
- **The Japandi set and the Botanical set are designed to hang together** — same paper, same ink, same line weight, same composition rule. After generating all 12, lay them out in a 3×4 grid to confirm they read as one family.
